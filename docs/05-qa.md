### Manual Test Procedures

| Test Case | Steps | Expected Result |
|-----------|-------|-----------------|
| Analyze valid YouTube URL | POST `/api/analyze` with valid URL | Returns clips array with start/end/title |
| Analyze invalid URL | POST `/api/analyze` with non-YouTube URL | Returns 400 error |
| Analyze video without subtitles | POST `/api/analyze` with video lacking subtitles | Returns error about missing subtitles |
| Download video | POST `/api/download` with valid videoId | Video file created in `videos/` |
| Render clip | POST `/api/render` with valid params | Clip file + thumbnail created, DB records inserted |
| Delete clip | POST `/api/delete` with valid clip URL | Files removed, clips.json updated |
| Gallery display | GET `/api/gallery` | Returns grouped clips from clips.json |
| Gallery refresh | POST `/api/gallery/refresh` | Re-queries SQLite database |
| Grid generation | POST `/api/grid` with valid clip URL | Grid image generated and returned |
| Shot segmentation | POST `/api/shots` with clip URL + video context | Returns shot array with labels and URLs |
| Shot listing | GET `/api/shots/{clipId}` | Returns previously segmented shots |
| WebSocket progress | Connect to `/ws/progress`, subscribe to jobId | Receives progress events in real-time |
| Session restore | Close browser, reopen app | Restores clips from localStorage + server |
| Proxy configuration | Set `HTTPS_PROXY` in .env | yt-dlp and API calls use proxy |

## Known Issues

### External Dependencies
- **yt-dlp**: May fail on age-restricted videos; workaround: `YT_DLP_COOKIES_BROWSER=chrome`. Adjust `YTDLP_TIMEOUT_MS` / `YTDLP_RETRIES` when downloads are slow to give yt-dlp more time/retries.
- **FFmpeg**: `codec: copy` may produce clips with minor A/V sync drift on some codecs
- **OpenAI API**: Rate limits may affect batch analysis of long videos; LLM response format occasionally requires fallback parsing

### Edge Cases
- Videos without subtitles: Cannot analyze; user receives error
- Very long videos (>2h): Subtitle batching may exceed LLM context; handled by windowing (max 300 lines)
- Duplicate clips: Deduplicated by start/end time overlap detection
- Database migrations: Schema changes require running `drizzle-kit generate` and `drizzle-kit migrate`
- Shot segmentation without video context: Works in fallback mode, but labels may be less accurate
